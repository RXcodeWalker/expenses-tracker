# Personal Expense Tracker

A Python-based expense tracking application that stores expenses in an Excel spreadsheet. Users can add expenses, view spending history, calculate total spending, analyze spending by category, and generate a pie chart visualization of their expenses.

Technologies Used:

- Python
- OpenPyXL
- Matplotlib

Key Concepts Demonstrated:

- Object-Oriented Programming
- File Handling
- Excel Data Management
- Data Analysis
- Data Visualization
